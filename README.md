# DocuMind AI

DocuMind AI is a SaaS platform for multimodal document, audio and video processing, analysis and content generation.

## Repositories

- `frontend/`: Frontend application.
- `backend/`: Backend API and business logic.
- `docs/`: Product specifications, architecture and technical documentation.

Each directory is maintained as an independent Git repository and integrated here as a Git submodule.

## Clone

```bash
git clone --recurse-submodules https://github.com/ToavinaJr/documind-ai.git
```
